## Bölüm B — Sosyal Medya Pazarlama Agent'ı (önceki plan)

ZCode tarayıcısında çalışan Langflow'a (http://127.0.0.1:7860) akışı eklerim:

```
Chat Input ──(input_value)──►  Agent  ──(response)──►  Chat Output
Prompt ──────(system_prompt)──►▲
```

- **Prompt** (Türkçe sistem talimatı): her brief için 4 platformda içerik üret — X (≤280 kr + thread varyantı), Instagram (caption + 10-15 hashtag + görsel önerisi), Facebook (hikâye anlatımı + CTA), LinkedIn (profesyonel ton) — her platform için 2 varyant, hedef kitle odaklı
- **Agent**: model seçici hazır; çalıştırma için kullanıcının API anahtarını girmesi yeterli
- Uygulama: starter JSON'dan türet → `POST /api/v1/flows/` (autologin token) → tarayıcıda aç + ekran görüntüsü doğrulaması → sekme sana kalır
- Not: Akış içerik üretir; platformlara otomatik paylaşım yapmaz (istersen sonra Webhook/API ile ekleriz)
